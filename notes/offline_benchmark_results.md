# Offline grouping benchmark: full results

- Task: Pursuit, 16 pursuers, Gaussian reward noise.
- Data: a 20-iteration MAPPO stream from a policy trained on clean rewards.
- Generated by `BenchMARL/examples/reward_robustness/offline_grouping_benchmark.py`.
- Budget: classifiers 10 epochs per batch, reward models 5 epochs unless the name says `e1`; warm-up on 10 clean batches.
- Cells: **SNR** (within-step capture contrast / residual noise std on non-capture samples). See the script docstring for definitions.
- Names: `rm` = reward model on (o, a); `rm_next` = on (o, a, o'); `_ens` = 5-head bootstrapped ensemble with confidence gating; `_gate` = out-of-sample skill gate (z ≥ 3); `nogate` = gate disabled. Rows without `gate` in the name predate the gate, i.e. ungated.
